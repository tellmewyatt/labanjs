# LabanJS

The purpose of LabanJS is to create a system for music composition using Labanotation and
MediaPipe to enable composers to easily create interactive scores for laptop ensemble performance.


## Installation

LabanJS can be built from this repository using `npm run pack`. You can then install the package in your node.js project using `npm install <path-to-package>`, replacing `<path-to-package>` with the name of the file you just created.

## Usage

Run `npm run dev` in this repository to run a simple page with the implementation of this software. You can run `npm run docs` to generate the documentation, which can then be accessed from `http://localhost:5173/docs/`.
